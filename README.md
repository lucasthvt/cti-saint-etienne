# Maquette du rapport d'activité — CTI Saint-Étienne

Maquette d'un site web de rapport d'activité, réalisée pendant mon stage de développement web au CTI Saint-Étienne (mai – juin 2026).

Elle a été construite à partir des données du **rapport d'activité 2016**. Les noms, les chiffres et les coordonnées sont **volontairement masqués** (« XXX ») et les textes sont remplacés par du **lorem ipsum**. Cette maquette est une démonstration non officielle.

Elle fait partie de mon portfolio : https://lucasthvt.github.io/projets/maquette-cti.html

## Ce que contient la page

- une page d'accueil avec le titre du rapport ;
- des **chiffres clés** ;
- les **missions**, présentées en cinq panneaux, chacun avec une image ;
- une **chronologie des temps forts**, filtrable mois par mois ;
- un **éditorial** (mot du directeur) et des informations de contact.

## Technologies

HTML, CSS et JavaScript, dans un seul fichier, sans framework ni dépendance.

## Structure

| Fichier | Rôle |
|---|---|
| `index.html` | La page (structure, styles et scripts) |
| `ASM_logo_white.png` | Logo |
| `aa.png`, `datasevrer.jpg`, `rack.jpg`, `reunion cti.jpg`, `tealmwork.jpg` | Images d'illustration |

## Voir la page en local

Ouvrir `index.html` dans un navigateur, ou lancer `python3 -m http.server` puis aller sur http://localhost:8000.
